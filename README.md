# WordMagic 🪄

AI-driven English vocabulary learning desktop app for primary school students, based on the Cambridge English graded word system.

## Features

- **Word Learning**: Flashcard mode with TTS pronunciation and example sentences
- **Practice Games**: Three game modes — Cloze Fill-in, Spelling Bee, and Picture Match
- **AI-Powered Questions**: Dynamic question generation via DeepSeek / Qwen / Doubao (falls back to built-in questions without API key)
- **Cambridge Word Bank**: Graded vocabulary across Starters (Pre-A1), Movers (A1), Flyers (A2), and KET (A2+)
- **Custom Word Import**: Add your own word lists
- **Progress Tracking**: Learning stats, 7-day activity chart, and achievement system
- **Child-Friendly UI**: Large fonts, bright colors, emoji icons, and playful animations
- **Offline Core**: Word learning and practice work offline; AI and image search need internet

## Tech Stack

- **Frontend**: Vue 3 (Composition API) + Vite + Pinia + Vue Router
- **Desktop**: Electron
- **TTS**: Web Speech API
- **AI**: DeepSeek (recommended) / Qwen / Doubao
- **Storage**: LocalStorage (progress + settings), Electron IPC (image cache)

## Getting Started

```bash
# Install dependencies
npm install

# Run in browser (dev mode)
npm run dev

# Run as Electron desktop app
npm run electron:dev

# Build for production
npm run build

# Package as desktop installer
npm run electron:build
```

## AI Provider Setup

1. Go to Settings
2. Choose a provider (DeepSeek recommended for best price/performance)
3. Enter your API key
4. Practice questions will be dynamically generated by AI

Without an API key, the app uses built-in question templates so all features remain functional.
